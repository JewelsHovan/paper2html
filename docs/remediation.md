## Remaining limits

- Native PDF/SVG parsing is not sandboxed or preempted by a process deadline. Ingestion bounds bytes/pages/pixels; direct adapters do not inherit all those guards. Use external CPU/memory/process isolation for hostile workloads.
- HTTP deadlines are checked between blocking operations, not hard process-kill guarantees. URL policy limits supported origins and SVG features intentionally; compatibility is not universal.
- SVG data URIs use the same validator; embedded raster data must be prevalidated, bounded, and served by exact mapping. External/file/nested SVG fetches remain forbidden. Real Cairo tests cover representative dvisvgm, matplotlib and embedded-raster fixtures, not every exporter.
- Budget admission uses unverified prices and heuristic estimates, not provider invoices. Unknown dispatched usage retains reservations; already-dispatched work can exceed an estimate. No live-provider performance or billing claims are made.
- Cache clear is not supported concurrently with processing. Legacy/unregistered artifacts remain by design. Abandoned temporary files/snapshots after SIGKILL and empty owned directories are retained (manual inspection/cleanup only, no broad sweep). Catalog metadata failures warn without losing published content; security path refusals still fail closed. Original library title/authors are intentionally preserved on upsert. Filesystem protection is not a guarantee against an adversarial process continuously replacing directories during operations.
- Partial results are useful but not complete evidence. Scientific claims and annotations require human review. `inspect` and `cache stats` remain stubs.
- Offline browser acceptance uses Chromium, not a multi-engine accessibility certification. Fonts/images, tooltip focus and hover, summary visibility/labels, proof keyboard controls, backlinks and table-only math are checked with real browser APIs. No production HTML or user caches are fixtures.
- Benchmark timings are baseline observations on the recorded dirty working tree. They are not optimization gains and cannot be compared as portable pass/fail thresholds. See `benchmarks/README.md`.

## Gates

`.github/workflows/checks.yml` provisions locked Python dependencies, native Cairo and Chromium, then runs lint, formatting, offline pytest, explicit offline browser acceptance and a bounded benchmark correctness smoke. Browser installation/registry access is provisioning, not a live data/provider test. The native Cairo import/conversion assertion prevents an optional-test skip from masquerading as a native gate pass.
